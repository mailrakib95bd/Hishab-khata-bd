# হিসাব-খাতা — ইনস্টলযোগ্য ওয়েব-অ্যাপ (PWA)

এই ফোল্ডারে আপনার `hisab-khata.jsx` কে একটি সম্পূর্ণ, ফোনে ইনস্টল করা যায় এমন
ওয়েব-অ্যাপ (Progressive Web App) হিসেবে প্যাকেজ করা হয়েছে।

## ফাইলগুলো কী করে
- `index.html` — মূল পেজ। React ও Babel ব্রাউজারে লোড করে `app.js` (আপনার
  অ্যাপের কোড) সরাসরি চালায় — আলাদা করে বিল্ড/কম্পাইল করার দরকার নেই।
- `app.js` — আপনার `hisab-khata.jsx`-এর কোড (শুধু `import`/`export` লাইন
  সরানো হয়েছে যাতে ব্রাউজারে সরাসরি চলে; ভেতরের সব ফিচার অপরিবর্তিত)।
- `manifest.json` — ফোনের হোম স্ক্রিনে "ইনস্টল" করার তথ্য (নাম, আইকন, রং)।
- `sw.js` — সার্ভিস ওয়ার্কার, যা একবার খোলার পর অফলাইনেও অ্যাপ চালু রাখতে সাহায্য করে।
- `icon-192.png`, `icon-512.png` — অ্যাপ আইকন।

## কীভাবে চালাবেন / ইনস্টল করবেন
সার্ভিস ওয়ার্কার ও "ইনস্টল" ফিচার কাজ করতে হলে এটি HTTPS-এ হোস্ট করা লাগবে
(শুধু ফাইল ডাবল-ক্লিক করে খুললে হিসাব রাখা কাজ করবে, কিন্তু অফলাইন/ইনস্টল
ফিচার কাজ নাও করতে পারে)। সবচেয়ে সহজ ফ্রি উপায়:

1. **GitHub Pages**: এই ফোল্ডারের ফাইলগুলো একটি GitHub রিপোজিটরিতে আপলোড
   করুন → Settings → Pages থেকে চালু করুন। কিছুক্ষণ পর একটি লিংক পাবেন।
2. **Netlify Drop** (netlify.com/drop): এই ফোল্ডারটি সরাসরি টেনে
   (drag-and-drop) দিলেই একটি লিংক তৈরি হয়ে যাবে — কোনো অ্যাকাউন্ট ছাড়াই।
3. **Vercel / Cloudflare Pages**: একইভাবে ফোল্ডার আপলোড করে ফ্রি হোস্ট করা যায়।

লিংক পাওয়ার পর ফোনের ব্রাউজারে (Chrome/Safari) খুলুন → মেনু থেকে
**"Add to Home Screen" / "হোম স্ক্রিনে যোগ করুন"** চাপুন — তাহলে এটি একটি
সাধারণ অ্যাপ আইকনের মতো ইনস্টল হয়ে যাবে এবং পূর্ণ স্ক্রিনে চলবে।

## ডেটা কোথায় থাকে
অ্যাপটি ফোনের ব্রাউজারের `localStorage`-এ ডেটা সংরক্ষণ করে — অর্থাৎ ডেটা
থাকে সম্পূর্ণ আপনার ডিভাইসেই, কোনো সার্ভারে যায় না। ব্রাউজারের ডেটা/ক্যাশ
মুছে ফেললে হিসাবও মুছে যাবে, তাই মাঝে মাঝে সেটিংস থেকে CSV এক্সপোর্ট করে
ব্যাকআপ রাখা ভালো।

## Play Store-এ APK হিসেবে দিতে চাইলে
সরাসরি এই পরিবেশে APK তৈরি করা সম্ভব হয়নি (Android build টুলচেইন ও নেটওয়ার্ক
এখানে নেই)। হোস্ট করার পর নিচের যেকোনো ফ্রি টুল দিয়ে এই PWA-কে APK-এ রূপান্তর
করা যায়:
- **PWABuilder** (pwabuilder.com) — লিংক দিলে এক ক্লিকে APK/AAB বানিয়ে দেয়।
- **Capacitor** (capacitorjs.com) — বেশি কাস্টমাইজেশন দরকার হলে।

## Phase 2 — ক্লাউড অ্যাকাউন্ট / Backup চালু করা

অ্যাপে এখন Settings → "অ্যাকাউন্ট" থেকে Google বা ইমেইল দিয়ে সাইন-ইন করে
ক্লাউডে ব্যাকআপ/সিঙ্ক করা যায়। এটা কাজ করানোর জন্য Firebase কনসোলে দুটো
ছোট কাজ করতে হবে (একবারই):

1. **Firestore Security Rules বসানো** — এই ফোল্ডারের `firestore.rules`
   ফাইলের পুরো লেখাটা কপি করুন → Firebase Console → আপনার প্রজেক্ট →
   Build → Firestore Database → **Rules** ট্যাব → পুরনো লেখা মুছে এটা
   পেস্ট করে **Publish** চাপুন। এটা ছাড়া কেউ কারো ডেটা লিখতে/পড়তে
   পারবে না (এমনকি নিজেরটাও না)।

2. **Authorized domain যোগ করা (Google Sign-In-এর জন্য জরুরি)** —
   Firebase Console → Authentication → Settings → **Authorized domains**
   ট্যাবে গিয়ে আপনার হোস্ট করা লিংকের ডোমেইনটা (যেমন
   `yourapp.netlify.app`) যোগ করুন। এটা ছাড়া Google দিয়ে সাইন-ইন করলে
   `auth/unauthorized-domain` এরর দেখাবে।

**গুরুত্বপূর্ণ পার্থক্য — কোন ভার্সনে কী কাজ করবে:**
- **হোস্ট করা ভার্সন** (এই zip, Netlify/GitHub Pages-এ আপলোড করার পর):
  Google Sign-In ও ইমেইল লগইন — দুটোই ঠিকমতো কাজ করবে।
- **`hisab-khata-standalone.html`** (সরাসরি ফোনে খোলা, হোস্ট করা ছাড়া):
  ইমেইল/পাসওয়ার্ড লগইন হয়তো কাজ করবে, কিন্তু **Google Sign-In কাজ
  নাও করতে পারে** — Google-এর OAuth পদ্ধতি একটা আসল ওয়েব ঠিকানা
  (https://...) দাবি করে, `file://`/`content://` থেকে না। ক্লাউড
  ফিচার পুরোপুরি ব্যবহার করতে চাইলে হোস্ট করা ভার্সনটাই ব্যবহার করুন।

**ডেটা কোথায় থাকে:** প্রতিটি ব্যবহারকারীর সব হিসাব একটামাত্র নথিতে —
`users/{আপনার UID}` — জমা থাকে Firestore-এ। ডিভাইসের PIN কখনো ক্লাউডে
পাঠানো হয় না, সেটা শুধু সেই ডিভাইসেই থাকে।

## 🛒 ফ্যামিলি বাজার (Family Bazar)

পরিবারের সবাই নিজের বাজার লেখে; কে কত খরচ করল, কোন পণ্যের দাম বাড়ল/কমল, এলাকাভেদে দামের তুলনা — সব এক জায়গায়। ব্যক্তিগত হিসাব-খাতার ডেটা এতে বদলায় না।

**কোথায় আছে:** ☰ মেনু → *ফ্যামিলি বাজার* (ফুল-স্ক্রিন) এবং নিচের *ফ্যামিলি* ট্যাবের প্রথম অংশ। ট্যাবের দ্বিতীয় অংশ *ব্যক্তিগত তালিকা* — আগের লোকাল পরিবার/বাজার তালিকা, অপরিবর্তিত।

| ফাইল | কাজ |
| --- | --- |
| `family-bazar-core.js` | শুধু লজিক (টাকার হিসাব, অনুমতি, দামের বিশ্লেষণ, write-plan) — Node-এ টেস্টযোগ্য |
| `family-bazar.js` | সব স্ক্রিন (Home, Bazar, Reports, Family, More + sheets) |
| `firebase-init.js` | Firestore ডেটা-লেয়ার (`window.FB`) |
| `firestore.rules` | **আসল সিকিউরিটি** — ফ্রন্টএন্ড লুকানোর ওপর ভরসা নেই |
| `tests/` | `npm test` — core (৪২) + expense-sync (৭) + task-amount (৪) + UI smoke (৩৫) = ৮৮টি |

**Deploy করার ধাপ**
1. Firebase Console → Firestore → Rules-এ `firestore.rules` পেস্ট করে Publish।
2. Authentication → Sign-in method-এ Google চালু; Settings → Authorized domains-এ আপনার ডোমেইন যোগ।
3. কোনো composite index লাগে না (সব কোয়েরি equality-ভিত্তিক)।
4. `index.html`-এ `?v=` এবং `sw.js`-এর `CACHE_NAME` বাড়ানো আছে — পুরনো cache নিজে থেকে বদলাবে।

**Invitation:** কোনো ইমেইল যায় না। প্রাপক ওই Gmail দিয়ে Google Sign In করলে ফ্যামিলি বাজারে Invitation দেখতে পান (☰ মেনুতে ব্যাজও আসে) এবং Accept করেন। ইমেইল/পাসওয়ার্ড অ্যাকাউন্ট থেকে Accept করা যায় না, কারণ সেই ইমেইল যাচাই করা থাকে না।

### ফ্যামিলি বাজার থেকে ব্যক্তিগত ব্যয়ে অটো-সিঙ্ক

কেউ ফ্যামিলি বাজারে একটি কেনাকাটা সংরক্ষণ করলে সেটা তার **নিজের** ব্যক্তিগত হিসাব-খাতার লেনদেনেও একটি নির্দিষ্ট ক্যাটাগরিতে ("🛒 ফ্যামিলি বাজার") যোগ হয়ে যায় — যাতে ব্যক্তিগত রিপোর্ট/ব্যালেন্সেও এটা ধরা পড়ে। এই ক্যাটাগরিটি প্রথমবার লাগলে নিজে থেকেই তৈরি হয়ে যায়, পরে কেউ নাম বদলালে সেটাই ব্যবহার হয়। কেনাকাটা এডিট/মুছে ফেললে সংশ্লিষ্ট লেনদেনও আপডেট/মুছে যায় (`purchaseId` দিয়ে লিংক করা)। পরিবারের অন্য সদস্যরা এই কেনাকাটা আগে থেকেই ফ্যামিলি ট্যাব থেকে দেখতে পান (অনুমতি অনুযায়ী) — তাই এই সিঙ্ক শুধু কেনার ব্যক্তির নিজের হিসাবে যোগ করে, অন্য কারও একাউন্টে কিছু লেখে না।

### বাজারের তালিকা (Shopping Lists) + রিমাইন্ডার

- যেকোনো সদস্য (viewer বাদে) নিজের জন্য বা পরিবারের অন্য যেকোনো সক্রিয় সদস্যের জন্য একটি "কী কিনতে হবে" তালিকা বানাতে পারেন (আরও ট্যাব → বাজারের তালিকা, অথবা হেডারের 📝 আইকন)।
- তালিকায় ঐচ্ছিক রিমাইন্ডার দেওয়া যায় — নির্দিষ্ট তারিখে একবার, অথবা প্রতিদিন — যতক্ষণ তালিকায় কেনা বাকি থাকে।
- রিমাইন্ডার শুধু তখনই কাজ করে যখন যাকে অ্যাসাইন করা হয়েছে তার ডিভাইসে অ্যাপ খোলা থাকে (২০ সেকেন্ড পরপর চেক হয়, ঠিক app-এর নিজের Task রিমাইন্ডারের মতোই) — এটা একটা client-only PWA, তাই অ্যাপ পুরো বন্ধ থাকা অবস্থায় নোটিফিকেশন পাঠানো সম্ভব নয় (তার জন্য push server লাগবে)।
- ফ্যামিলি/ফ্যামিলি বাজারের হেডারে 📝 আইকনে তালিকায় কতগুলো পণ্য বাকি আছে তার সংখ্যা ছোট্ট ব্যাজ আকারে দেখা যায়।
- তালিকার যেকোনো পণ্যের নামে চাপ দিলে ঠিক "নতুন বাজার যোগ করুন" ফর্মের মতোই একটি ফর্ম খোলে (নাম/পরিমাণ/একক আগে থেকে ভরা, দাম ফাঁকা) — সংরক্ষণ করলে সেটা প্রকৃত কেনাকাটা ও ব্যক্তিগত খরচ হিসেবে যোগ হয়ে যায়, আর তালিকা থেকে সরে যায়; বাকি পণ্যগুলো তালিকাতেই থেকে যায়। একাধিক পণ্য একসাথে কিনলে "সবগুলো দিয়ে একসাথে বাজার যোগ করুন" বাটন দিয়ে একবারে করা যায়।
- চেকবক্স দিয়ে দাম ছাড়াই কোনো পণ্য "সম্পন্ন" হিসেবে চিহ্নিত করা যায় (কেনাকাটা/খরচ তৈরি হয় না, শুধু কেটে দেখানো হয়)।
- একটি তালিকা শুধু তৈরিকারী, যাকে অ্যাসাইন করা হয়েছে, ও মালিক/এডমিন দেখতে পারেন — Firestore rules-এ প্রয়োগ করা, ফ্রন্টএন্ডে লুকানো নয়।

## 📋 টাস্ক (Header-এর ছোট ক্যালেন্ডার আইকনের পাশে)

বিস্তারিত টাস্ক ফর্মে (নাম, তারিখ, সময়, সাব-ক্যাটাগরি, নোট, রিমাইন্ডার প্রিসেট, রিপিট) এখন একটি ঐচ্ছিক **পরিমাণ/টাকা** ফিল্ড আছে ("সাব-ক্যাটাগরি"-র ঠিক নিচে) — এটি বাধ্যতামূলক নয় (কোনো `*` নেই), খালি রাখলে বা ভুল সংখ্যা দিলে চুপচাপ `null` হিসেবে সংরক্ষণ হয়। টাস্ক লিস্টে থাকলে এটি সোনালি রঙে দেখা যায়। এটি শুধু একটি তথ্যমূলক নম্বর — Family Bazar-এর মতো এটা কোনো লেনদেনে রূপান্তর হয় না।
