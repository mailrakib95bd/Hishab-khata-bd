# হিসাব-খাতা — ইনস্টলযোগ্য ওয়েব-অ্যাপ (PWA)

এই ফোল্ডারে আপনার `hisab-khata.jsx` কে একটি সম্পূর্ণ, ফোনে ইনস্টল করা যায় এমন
ওয়েব-অ্যাপ (Progressive Web App) হিসেবে প্যাকেজ করা হয়েছে।

## ফাইলগুলো কী করে
- `index.html` — মূল পেজ। React ও Babel ব্রাউজারে লোড করে `app.js` (আপনার
  অ্যাপের কোড) সরাসরি চালায় — আলাদা করে বিল্ড/কম্পাইল করার দরকার নেই।
- `app.js` — আপনার `hisab-khata.jsx`-এর কোড (শুধু `import`/`export` লাইন
  সরানো হয়েছে যাতে ব্রাউজারে সরাসরি চলে; ভেতরের সব ফিচার অপরিবর্তিত)।
- `manifest.json` — ফোনের হোম স্ক্রিনে "ইনস্টল" করার তথ্য (নাম, আইকন, রং)।
- `sw.js` — সার্ভিস ওয়ার্কার, যা একবার খোলার পর অফলাইনেও অ্যাপ চালু রাখতে সাহায্য করে।
- `icon-192.png`, `icon-512.png` — অ্যাপ আইকন।

## কীভাবে চালাবেন / ইনস্টল করবেন
সার্ভিস ওয়ার্কার ও "ইনস্টল" ফিচার কাজ করতে হলে এটি HTTPS-এ হোস্ট করা লাগবে
(শুধু ফাইল ডাবল-ক্লিক করে খুললে হিসাব রাখা কাজ করবে, কিন্তু অফলাইন/ইনস্টল
ফিচার কাজ নাও করতে পারে)। সবচেয়ে সহজ ফ্রি উপায়:

1. **GitHub Pages**: এই ফোল্ডারের ফাইলগুলো একটি GitHub রিপোজিটরিতে আপলোড
   করুন → Settings → Pages থেকে চালু করুন। কিছুক্ষণ পর একটি লিংক পাবেন।
2. **Netlify Drop** (netlify.com/drop): এই ফোল্ডারটি সরাসরি টেনে
   (drag-and-drop) দিলেই একটি লিংক তৈরি হয়ে যাবে — কোনো অ্যাকাউন্ট ছাড়াই।
3. **Vercel / Cloudflare Pages**: একইভাবে ফোল্ডার আপলোড করে ফ্রি হোস্ট করা যায়।

লিংক পাওয়ার পর ফোনের ব্রাউজারে (Chrome/Safari) খুলুন → মেনু থেকে
**"Add to Home Screen" / "হোম স্ক্রিনে যোগ করুন"** চাপুন — তাহলে এটি একটি
সাধারণ অ্যাপ আইকনের মতো ইনস্টল হয়ে যাবে এবং পূর্ণ স্ক্রিনে চলবে।

## ডেটা কোথায় থাকে
অ্যাপটি ফোনের ব্রাউজারের `localStorage`-এ ডেটা সংরক্ষণ করে — অর্থাৎ ডেটা
থাকে সম্পূর্ণ আপনার ডিভাইসেই, কোনো সার্ভারে যায় না। ব্রাউজারের ডেটা/ক্যাশ
মুছে ফেললে হিসাবও মুছে যাবে, তাই মাঝে মাঝে সেটিংস থেকে CSV এক্সপোর্ট করে
ব্যাকআপ রাখা ভালো।

## Play Store-এ APK হিসেবে দিতে চাইলে
সরাসরি এই পরিবেশে APK তৈরি করা সম্ভব হয়নি (Android build টুলচেইন ও নেটওয়ার্ক
এখানে নেই)। হোস্ট করার পর নিচের যেকোনো ফ্রি টুল দিয়ে এই PWA-কে APK-এ রূপান্তর
করা যায়:
- **PWABuilder** (pwabuilder.com) — লিংক দিলে এক ক্লিকে APK/AAB বানিয়ে দেয়।
- **Capacitor** (capacitorjs.com) — বেশি কাস্টমাইজেশন দরকার হলে।

## Phase 2 — ক্লাউড অ্যাকাউন্ট / Backup চালু করা

অ্যাপে এখন Settings → "অ্যাকাউন্ট" থেকে Google বা ইমেইল দিয়ে সাইন-ইন করে
ক্লাউডে ব্যাকআপ/সিঙ্ক করা যায়। এটা কাজ করানোর জন্য Firebase কনসোলে দুটো
ছোট কাজ করতে হবে (একবারই):

1. **Firestore Security Rules বসানো** — এই ফোল্ডারের `firestore.rules`
   ফাইলের পুরো লেখাটা কপি করুন → Firebase Console → আপনার প্রজেক্ট →
   Build → Firestore Database → **Rules** ট্যাব → পুরনো লেখা মুছে এটা
   পেস্ট করে **Publish** চাপুন। এটা ছাড়া কেউ কারো ডেটা লিখতে/পড়তে
   পারবে না (এমনকি নিজেরটাও না)।

2. **Authorized domain যোগ করা (Google Sign-In-এর জন্য জরুরি)** —
   Firebase Console → Authentication → Settings → **Authorized domains**
   ট্যাবে গিয়ে আপনার হোস্ট করা লিংকের ডোমেইনটা (যেমন
   `yourapp.netlify.app`) যোগ করুন। এটা ছাড়া Google দিয়ে সাইন-ইন করলে
   `auth/unauthorized-domain` এরর দেখাবে।

**গুরুত্বপূর্ণ পার্থক্য — কোন ভার্সনে কী কাজ করবে:**
- **হোস্ট করা ভার্সন** (এই zip, Netlify/GitHub Pages-এ আপলোড করার পর):
  Google Sign-In ও ইমেইল লগইন — দুটোই ঠিকমতো কাজ করবে।
- **`hisab-khata-standalone.html`** (সরাসরি ফোনে খোলা, হোস্ট করা ছাড়া):
  ইমেইল/পাসওয়ার্ড লগইন হয়তো কাজ করবে, কিন্তু **Google Sign-In কাজ
  নাও করতে পারে** — Google-এর OAuth পদ্ধতি একটা আসল ওয়েব ঠিকানা
  (https://...) দাবি করে, `file://`/`content://` থেকে না। ক্লাউড
  ফিচার পুরোপুরি ব্যবহার করতে চাইলে হোস্ট করা ভার্সনটাই ব্যবহার করুন।

**ডেটা কোথায় থাকে:** প্রতিটি ব্যবহারকারীর সব হিসাব একটামাত্র নথিতে —
`users/{আপনার UID}` — জমা থাকে Firestore-এ। ডিভাইসের PIN কখনো ক্লাউডে
পাঠানো হয় না, সেটা শুধু সেই ডিভাইসেই থাকে।
